# Streak Bot

This is a bot that allows you to keep track of your streaks. You can add and remove streaks freely. The main command it has it /streak which allows you to see all of your streaks. You can go to the home tab to see more capabilities. Overall this is really helpful if you're participating in multiple events that require you to do a certain amount of work every day.  

If you want to install this on your own workspace you will need to run slack create and slack run in order to add it. You will need to install the Slack CLI to do this: https://docs.slack.dev/tools/slack-cli/guides/installing-the-slack-cli-for-windows/.  

Something to note: This app is untested because of errors happening on my machine stopping me from running it in a workspace.
