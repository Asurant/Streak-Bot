# Streak Bot

This is a bot that allows you to keep track of your streaks. You can add and remove streaks freely. You can go to the home tab to use it. Overall this is really helpful if you're participating in multiple events that require you to do a certain amount of work every day. /streakbot-streaks shows the streaks you have

If you want to install this on your own workspace you will need to run slack create and slack run in order to add it. You will need to install the Slack CLI to do this: https://docs.slack.dev/tools/slack-cli/guides/installing-the-slack-cli-for-windows/.
